## Summary Report

### Event Objectives

The session aimed to explore and analyze the most popular communication standards used in modern software systems, including REST, GraphQL, WebSockets, gRPC, MCP, and others. The goal was to help participants understand the strengths, weaknesses, and suitable use cases of each protocol in order to make better architectural decisions.

### Key Topics

**1. REST**
- Principles of RESTful architecture
- Advantages and limitations
- Common use cases in web and mobile applications

**2. GraphQL**
- Flexible data querying
- Solving over-fetching and under-fetching problems
- Comparison with REST

**3. WebSockets**
- Persistent bi-directional communication
- Real-time applications (chat, gaming, live updates)
- When to choose WebSockets over HTTP

**4. gRPC**
- High-performance RPC framework
- Protocol Buffers and HTTP/2
- Suitable for microservices and internal communication

**5. MCP and Other Emerging Standards**
- Introduction to newer communication protocols
- Use cases and current adoption trends

### Key Takeaways

- There is no single best communication protocol; the choice depends on the specific requirements of the system.
- REST remains popular for its simplicity and wide adoption.
- GraphQL is powerful when clients need flexible data retrieval.
- WebSockets are ideal for real-time, bi-directional communication.
- gRPC offers high performance and is well-suited for service-to-service communication.
- Understanding multiple standards allows developers to design more efficient and scalable systems.

### Event Experience

This session provided a clear and structured comparison of modern communication standards. Learning about the trade-offs between REST, GraphQL, WebSockets, and gRPC helped me better understand when to apply each technology in real projects, especially in cloud and microservices architectures.

### Lessons Learned

- Choose the communication protocol based on use case, not popularity.
- Real-time features often require WebSockets or similar technologies.
- Performance-critical internal services can benefit from gRPC.
- Staying updated with emerging standards (such as MCP) is important for long-term architecture decisions.
