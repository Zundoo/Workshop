## Summary Report

### Event Objectives

The event aimed to provide students and aspiring cloud practitioners with a clear understanding of the roles in the data domain, the end-to-end lifecycle of Data & MLOps projects on AWS, and practical experience with Amazon SageMaker. It also offered career guidance and a learning roadmap for students who want to pursue careers in Data Science, Data Engineering, or MLOps.

### Key Topics

**01. The Big Picture: Understanding Data Engineers, Data Scientists, and Data Analysts**
- Clear distinction between the three main roles in the data ecosystem
- Responsibilities and daily tasks of each role
- How these roles collaborate in real-world projects

**02. Data & MLOps Project Lifecycle: How to build end-to-end projects on AWS**
- Overview of a complete Data & MLOps project lifecycle
- Key AWS services used in each stage (data ingestion, processing, training, deployment, monitoring)
- Best practices for building scalable and maintainable ML pipelines on AWS

**03. A Day as a Data Scientist: Hands-on practice using AWS SageMaker**
- Practical introduction to Amazon SageMaker
- Hands-on experience with data preparation, model training, and deployment
- Understanding the workflow of a Data Scientist in a cloud environment

**04. Roadmap & Advice: Career path and essential skills for students**
- Recommended learning path for students interested in Data Science / MLOps
- Essential technical and soft skills
- Practical advice from industry professionals on how to start a career in this field

### Key Takeaways

- Understanding the differences between Data Engineer, Data Scientist, and Data Analyst helps in choosing the right career direction.
- Building end-to-end Data & MLOps projects on AWS requires knowledge of multiple services working together.
- Amazon SageMaker significantly simplifies the machine learning workflow for Data Scientists.
- Having a clear roadmap and continuous learning mindset is essential for students entering the data field.

### Event Experience

Participating in this session gave me a clearer picture of the data career landscape and how AWS supports the entire Data & MLOps lifecycle. The hands-on part with Amazon SageMaker was particularly valuable, as it allowed me to experience real tools used by Data Scientists in the industry.

The career roadmap and advice section also helped me identify the skills I need to focus on and how to plan my learning journey more effectively.

### Lessons Learned

- Clarify the role I want to pursue (Data Engineer / Data Scientist / Data Analyst) early.
- Learn AWS services in the context of real project lifecycles instead of isolated tools.
- Practice with Amazon SageMaker to gain hands-on experience.
- Follow a structured roadmap and continuously improve both technical and soft skills.
