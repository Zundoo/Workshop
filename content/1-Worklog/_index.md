# Worklog

This section summarizes my internship progress over 8 weeks. Throughout the internship, I followed a structured learning roadmap that started with AWS fundamental services and gradually advanced to designing, developing, deploying, and operating a complete cloud-based application.

During the first weeks, I focused on learning AWS core services such as IAM, EC2, VPC, Amazon S3, Amazon RDS, Security Groups, Application Load Balancer, Amazon CloudWatch, Docker, and Amazon ECS. These activities provided the technical foundation required for the internship project.

In the later weeks, I applied the knowledge gained to design the system architecture, develop the application, and deploy the complete solution on AWS Cloud.

The internship project, **AWS Real-time Game Server**, was successfully developed and deployed using Amazon ECS Fargate, Docker, Application Load Balancer, Amazon RDS (MySQL), Amazon ElastiCache (Redis), Amazon CloudWatch, Security Groups, and VPC with Public/Private Subnets.
